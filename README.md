# 摸鱼大王

手机优先的放置养成小游戏原型。

## 当前机制
- 自动推关，5 关一个 Boss
- 英雄升级与主动技能
- 免费随机装备掉落、品质、词条、强化、分解
- 每 3 关策略三选一
- 办公室随机事件
- 精华研究树与永久升级
- 20 关后转生与永久摸鱼值
- 离线收益（最多 8 小时）
- 自动本地存档、JSON 导出/导入
- PWA，可添加到手机主屏幕
- 商城只做确定性商品；当前“充值”仅模拟，不发生真实支付

## 存档
存档保存在浏览器 localStorage。换手机、换浏览器或清缓存前请先在“存档”页导出 JSON。

## GitHub Pages
在仓库 Settings → Pages 中，把 Source 设为 Deploy from a branch，Branch 选择 main / root，即可发布。
